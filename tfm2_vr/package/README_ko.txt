팀파이트 매니저 2 VR (TFM2 VR) 0.1.1 - 창작마당판
================================================

팀파이트 매니저 2를 PC VR 헤드셋으로 보는 프로그램입니다.
경기는 테이블 위에 입체로, 시작·관리·밴픽 화면은 눈앞의 휜 큰 화면으로 나옵니다.
게임 화면을 그대로 받아 띄우므로 게임은 평소처럼 돌아갑니다.


필요한 것
---------
- Windows 10/11 64비트, 팀파이트 매니저 2 0.7.4
- PC VR 헤드셋과 OpenXR 런타임
  (Quest 3 + 에어 링크에서 확인. 유선 Link·Virtual Desktop·SteamVR 헤드셋은 미확인.
  Quest 단독 실행은 안 됩니다.)
- 실행이 안 되면 Microsoft Visual C++ 재배포 패키지(x64)


처음 한 번
----------
1. 구독하고 게임을 켜서 모드 메뉴에서 TFM2 VR 을 켜고(코드 모드 경고 허용) 게임을 다시 시작합니다.
2. 이 폴더를 엽니다:
   스팀 라이브러리 > 팀파이트 매니저 2 우클릭 > 관리 > 로컬 파일 보기
   → steamapps\common\Teamfight Manager2 가 열리면 두 단계 위로 올라가
   workshop\content\3009300\<이 항목 번호>\ 로 들어갑니다.
3. (선택) Make_Desktop_Shortcut.bat 을 실행하면 바탕 화면에 "TFM2 VR" 바로 가기가 생깁니다.


실행
----
1. 헤드셋을 PC 에 연결합니다. 헤드셋 앱이 PC 의 기본 OpenXR 런타임이어야 합니다
   (Meta 앱: 설정 > 일반 > OpenXR 런타임, SteamVR: 설정 > OpenXR).
2. TFM2_VR.bat(또는 바탕 화면 바로 가기)을 실행합니다. 게임이 저절로 켜지고,
   이미 켜져 있으면 그 게임에 붙습니다.
3. 끝낼 때는 게임을 끄거나 검은 창을 닫습니다.


조작
----
컨트롤러 레이저로 가리켜서 씁니다. 마우스와 같습니다.
- 트리거: 창 클릭 / 아무것도 안 가리키면 테이블 잡기
- 그립: 테이블 잡기
- 스틱: 창 스크롤 / 왼쪽 = 거리·높이, 오른쪽 = 회전·크기
- A / X: 가운데로      - B / Y: 자판 열기·닫기
- 두 손으로 잡고 벌리거나 돌리면 크기와 방향이 바뀝니다.
- 왼쪽 아래 단추 판: 휜 화면 ↔ 평평한 화면, 가운데로, 자판.


언어
----
VR 안내 글자는 게임 언어(한국어·영어)를 따릅니다. 바꾸려면 viewer.toml 의 lang 을 ko / en / auto 로.


알아 둘 것
----------
- 압축판(디시 배포판)을 설치한 적이 있으면 <게임 폴더>\mods\tfm2_vr_bridge 를 지워 주세요(모드가 두 번 읽힘).
- openxr_loader.dat 은 Khronos Group 의 OpenXR 로더(openxr_loader.dll, Apache License 2.0)입니다.
  게임이 모드 dll 로 착각해 읽지 않도록 이름만 바꿨습니다.
- 문제가 생기면 _tmp\logs 의 가장 최근 기록 파일을 같이 보내 주세요.
- 비공식 팬 모드입니다. 게임 개발사와 관련이 없습니다.
